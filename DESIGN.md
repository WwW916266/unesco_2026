# PIGEON Design System

## Product Feel

PIGEON should feel like a calm trust layer, not a security warning or a fact-checking verdict. The interface should be soft, premium, and low-friction: warm milk-blue surfaces, white space, clear hierarchy, and precise microcopy.

## Core Principles

- Progressive disclosure first: show a small nudge before a larger panel.
- Context over judgment: never present PIGEON as deciding true or false.
- Native platform feel: simulations should look like they belong inside the app moment.
- Credibility as behavior: trust tiers reward transparency, sourcing, correction, and AI disclosure.
- Non-censorship: every sharing flow keeps a subtle path to continue.

## Visual Language

- Surfaces: white or soft blue-tinted glass.
- Accent: trust blue for primary actions, green for positive transparency, amber for caution, coral/red for reconsideration.
- Corners: medium radii for tools and cards; pill shapes only for filters, badges, and compact status.
- Motion: small lift, glow, and drawer/capsule transitions. Avoid large decorative motion.
- Accessibility: visible focus states, strong text contrast, readable small labels.

## Component Rules

- PIGEON plugin UI uses progressive disclosure: collapsed capsule -> expanded drawer.
- Trust tier badges appear as suffixes next to the user ID.
- Creator flows show source readiness before publish.
- Viewer flows trigger only after a platform-native user action.
